联颌评估 · iPhone / iPad 版

包含咬合重建初诊评估、TMJ 风险快筛与 GCPS 慢性疼痛分级量表，采用蓝色配色，支持触控、横竖屏、牙位记录、JSON 导入导出及直接生成 PDF 报告。

银河首页与动效

打开后从银河首页选择初诊、TMJ 或 GCPS。工作台左上角的“首页”可返回入口；切换模块保留当前填写、照片和章节位置。浏览器的返回、前进与刷新会恢复地址中的对应视图。首页不会导出上一次患者的报告。

右上角可暂停或开启动效，也会自动跟随系统“减少动态效果”。首页与三个临床模块均提供星云动效。模块内使用动态星云标题、轻微背景漂移与桌面鼠标视差；正文保留浅色表单。仅当前模块的可见星云横幅运行；滚出视野、切换模块或应用进入后台后暂停。全部动画依赖和原创银河素材均在本地包中，无需外部 CDN。动画不可用时仍可正常填写。

本地预览

单文件 HTML 可在电脑中预览适配效果。iPhone / iPad 的安装与离线 App 模式，请使用部署后的网站地址；“文件”App 的预览不等同于 Safari 网页运行环境。

在 iPhone / iPad 上使用

  1. 将部署包内的全部文件放到同一个 HTTPS 网站目录，保留 icons 文件夹及相对路径。
  2. 在设备的 Safari 中打开该目录的 index.html，等待“更多”中的离线状态显示资源准备完成。
  3. 点 Safari 的“分享”→“添加到主屏幕”；如有“作为网页 App 打开”开关，请开启。
  4. 从主屏幕“联颌评估”图标进入。首次准备完成后，可断网重新打开三个评估模块。

Apple 官方主屏幕网页 App 使用说明

记录与换设备

资料保存在当前设备和浏览环境，不自动跨设备同步。离线缓存保存的是应用程序，并非患者资料备份。换设备、清理 Safari 或从文件版改用网站版前，请分别导出各模块的 JSON，再在新环境导入。

同一设备、同一网站来源下的网页版共用原有本机记录键。不同域名、文件版、Safari 与主屏幕 App 的记录可用性不应假定一致，推荐通过导出和导入转移。

初诊照片与影像

A 区支持正面照与正面微笑照；B 区第一排为右侧、正面、左侧咬合照，第二排上颌颌面照居左、下颌颌面照居右，五张照片等宽；辅助诊断区支持 OPG 与左右 TMJ 影像。点击卡片选择 JPG、PNG 或 WebP，每张不超过 12MB、全部原图不超过 96MB。预览与报告完整显示画面，原文件单独保存在本机，可点击放大查看。

照片随初诊 JSON 记录一并备份和恢复，PDF 使用全图报告副本。清空初诊记录会同时清空对应照片。照片不会上传到网站服务器；清理浏览器资料前请先导出记录。含照片的 JSON 文件较大，导入时请等待完成。

GCPS 慢性疼痛量表

保留原中文表的七道题与过去六个月时间范围，姓名、日期及编号单独记录。患者填写与医护评分分开显示；未完成或存在需要核对的回答时，不自动给出分级。计分口径会在评分区域和报告中注明。此模块使用独立本机记录键，不更改前两个模块的记录。

手机导出报告

在模块的“记录操作”或顶部“更多”选择“导出 PDF 报告”。文件直接在当前设备生成，不依赖系统打印，也不上传患者资料。生成完成后可选“分享 PDF”“保存 PDF 文件”“打开 PDF 预览”；分享是否可用取决于当前浏览器。

若微信、豆包等 App 限制文件保存，可查看逐页报告图片，并尝试长按保存。若需换到 Safari，请先备份 JSON，当前填写内容不会自动迁移到其他浏览环境。不要通过清除浏览器数据来更新应用。

PDF 采用逐页图文排版，便于查看与打印；文字内容的检索、复制和继续编辑请保留 JSON 记录。原系统打印作为备用入口保留。

已做的移动适配

  • 底部三模块导航、初诊表章节选择及触控操作菜单。
  • 表单输入字号 16px，保留用户缩放，扩大牙位与单选、多选操作区域。
  • 安全区留白、可视高度处理、键盘状态反馈与横竖屏布局。
  • PDF 按 A4 分页在本机生成，保留完整问卷、牙位、长备注及影像参考图。

测试与范围

提供浏览器设备尺寸与触控模拟测试、离线程序缓存和记录恢复测试。这是可添加到主屏幕的网页应用，不是 App Store 安装包。Safari 真机的软键盘、添加主屏幕、文件分享与下载和备用 AirPrint 仍需在你的 iPhone / iPad 上验收。建议使用较新的 iOS / iPadOS Safari。

部署文件

index.html、manifest.webmanifest、service-worker.js 和 icons/ 为应用程序。service-worker.js 需要作为 JavaScript 提供且建议使用 no-cache；manifest.webmanifest 使用 application/manifest+json。整个包可放网站根目录或子目录，不需要服务器数据库。
