# 联颌医疗 · 咬合重建多维诊疗评估系统

手机、iPad 与桌面浏览器可用的纯静态网页。

包含咬合重建初诊评估、颞下颌关节风险评估快筛和 GCPS 慢性疼痛分级三个模块。

## 部署

- Render 服务类型：Static Site
- 分支：main
- Build command：`test -f public/index.html`
- Publish directory：`public`
- 不需要环境变量、服务器、账号登录或数据库。

## 数据

仓库只包含空白表单及静态素材，不含病例资料。填写内容和照片保存在使用者当前浏览器本机；更换域名或设备不会自动迁移，需在原网站导出记录，再在新网站导入。

Safari 打开 HTTPS 网站后，可通过“分享 → 添加到主屏幕”使用。首次完整加载后缓存离线资源。

原有三个临床模块的内容、计分和交互保持不变。
